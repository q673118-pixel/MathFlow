# MathFlow 1.1.0 — interface redesign

- New minimal calculator screen: no app title, one display, large pill-shaped keys, centered layout without page scrolling.
- Scientific keys (sin, cos, tan, ln, log, abs, π, e, √, x², xʸ) are toggled with the f(x) chip; the keypad shrinks to fit instead of moving.
- DEG/RAD switch in scientific mode; open brackets are closed automatically on "=".
- Bottom navigation is a compact icon-only bar with five sections.
- Tools page shows one tool at a time (fractions, percentages, geometry) instead of three large cards.
- Equation solver has a symbol shortcut row (x, x², brackets, =).
- History is a flat list with date, time and expandable steps.
- Separate light and dark palettes (graphite + lavender in dark mode).
- Custom font is now applied through Material Typography and LocalTextStyle, so it reaches every text element.
- Math engine, solver and tools are unchanged.
